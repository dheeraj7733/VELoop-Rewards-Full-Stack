# Database Models
1. User: Identity & Auth
2. Wallet: Authoritative balances (VEs, SVEs, Gems, Tokens, XP, reserved)
3. WalletTransaction: Financial ledger
4. LevelConfiguration: Levels 1 to 6
5. Achievement & UserAchievement: Badges
6. Withdrawal: Payout requests
7. Referral: Invites and rewards
8. ActivityLog: User events
9. AdminAuditLog: Admin actions
